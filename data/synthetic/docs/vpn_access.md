# VPN Access

Remote employees connect through the company VPN before reaching internal apps.

## Setup
1. Install the company VPN client from the software catalog.
2. Sign in with SSO.
3. Select the `corp-employees` profile.
4. Confirm the status shows Connected.

## Troubleshooting
- Split tunneling is enabled; public websites do not need the VPN.
- If MFA fails repeatedly, wait 10 minutes and retry.
- For laptop re-images, request VPN re-enrollment in `#it-help`.
